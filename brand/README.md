# Noirr Runner — brand assets

Noirr Runner downloads, repairs, extracts, and hands off files. The public app
name is **Noirr Runner**; the short in-app name is **Runner**; the visual lockup
is `noirr_ runner`.

`icon-master.svg` is the canonical icon geometry. The red dash sits in the
negative space between the R's vertical stem and diagonal leg, clear of both
strokes. Generated PNGs live in `export/`.

The repository, binary, bundle identifier, URL scheme, service-discovery name,
configuration keys, API paths, and data directories remain `nzbd` for
compatibility. A public rename must not silently change those contracts.
